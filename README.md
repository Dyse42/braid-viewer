# The Braid — viewer

A public host for a private record. The braid itself is served here only as
AES-256-GCM ciphertext (`political-braid.json.enc`, PBKDF2-HMAC-SHA256);
it is decrypted in the browser, by passphrase, and never in a readable form on
this repo or on the wire.

Generated by `tools/publish_viewer.sh` in the source repo. Edits made here are
overwritten on the next publish.
